# Privacy and Security

All processing happens on the device. The vector index is stored in a local folder that can sit on a BitLocker-encrypted drive, protected by the TPM. HP business PCs add hardware-backed security features that complement this design.

Because nothing is uploaded, EdgeMind suits regulated teams such as legal, healthcare and finance, where documents cannot leave company hardware.

The application works offline, so it remains useful on flights and in low-connectivity locations.
